# Agent Guidelines

Welcome to the repository. When working in this workspace, agents should leverage the available tools and MCP servers outlined below.

---

## 1. Model Context Protocol (MCP) Tools

- **`book-rhino`**: Connected via Model Context Protocol (configured in `.agents/mcp_config.json`).
  - Use this server to query, create, update, and manage books, chapters, characters, plots, locations, and manuscript assets.
  - Inspect book state, run generation/iterations, and render scenes or chapters directly through the `book-rhino` MCP toolset.
